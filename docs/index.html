Espresso

Keep your Mac awake.

A tiny menu bar app that prevents your Mac from sleeping while you work. Toggle on demand or set a timer up to 5 hours. No dock icon. No Apple tax.

Recommended

Brew it in Terminal

One line installs to ~/Applications, ad-hoc signs the app, and clears Gatekeeper. This is how you skip “unidentified developer” without a paid Apple ID.

curl -fsSL https://eng-kitchen.github.io/espresso/install.sh | bash

macOS blocked it anyway?

Espresso is ad-hoc signed on purpose — no $99/year Developer ID, no notarization. If Finder still complains after a browser download:

  1. Prefer the Terminal brew above. It never leaves the quarantine bit set.
  2. If you already dragged the app: keep the disk image open and double-click Brew Espresso. If macOS blocks the helper too, right-click it → Open.
  3. Last resort, in Terminal: xattr -cr ~/Applications/Espresso.app /Applications/Espresso.app 2>/dev/null; open ~/Applications/Espresso.app
