## Brew it

```bash
curl -fsSL https://eng-kitchen.github.io/espresso/install.sh | bash
```

This installs to `~/Applications`, ad-hoc signs the app, and clears Gatekeeper — no Apple Developer ID required.

## Or download the café tray

Open `Espresso.dmg`, drag **Espresso** onto **Applications**, then double-click **Brew Espresso** on the disk image if macOS blocks the app.
